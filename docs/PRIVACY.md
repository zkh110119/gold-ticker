# Privacy Notice

Last updated: 2026-09-10

## What Gold Ticker processes

Gold Ticker requests the public Tencent `hf_XAU` quote endpoint to retrieve a gold quote. The request includes a timestamp cache-buster and the app's user agent. It does not use an account, API key, cookie, advertising identifier, or analytics SDK.

## Local data

Gold Ticker stores the following only on the Mac where it runs, under the macOS Application Support directory for the app:

- a user-configured price threshold;
- the most recent successful quote cache;
- bounded diagnostic logs containing redacted event names and timestamps.

The app uses this data to restore its display after launch, compare successive quotes, and diagnose app lifecycle/refresh failures. It does not transmit settings, cache contents, or diagnostic logs.

## What is not collected

Gold Ticker does not collect accounts, contact data, location data, payment data, browsing history, identifiers, or trading information. It does not sell, share, or upload personal information.

## Third-party service

Tencent operates the quote endpoint. Tencent's own terms and privacy practices govern that endpoint and any information it receives from a network request. Before public distribution, the publisher must review and document the endpoint's current terms, permitted use, rate limits, regional availability, and redistribution rights.
